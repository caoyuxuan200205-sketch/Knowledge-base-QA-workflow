# 知识库生产评测工作台

一个轻量、高效的面向公众导览的博物馆知识库生产与评测工作流。馆方可以导入现有 QA 表格或大纲大图文档，自动整理为高品质候选问答，完成机器事实审查、人工审核修改与标准评测集导出。

## 核心特性

- **多格式大文件支持**：批量拖拽导入 `.docx` (Word)、`.pdf`、`.xlsx`、`.xls`、`.csv`、`.txt`，**单个文件上限放宽至 100 MB**，纯浏览器端内存安全解析；
- **智能正文抽取与 OCR 提示**：Word 文件自动剔除大图媒体、秒级流式提取正文 XML；PDF 自动识别扫描无字页并提示需 OCR；
- **高品质金牌导览问答生成**：
  - **告别单薄应答**：单条问答建议 120~250 字，层次清晰（【核心结论】+【细节展开】+【观展看点/历史价值】）；
  - **多要素立体整合**：自动整合同一行或正文段落中的多维要素（年代、材质、纹饰、工艺、出土故事等），拒绝只回答单个参数；
  - **标准化覆盖五大体系**：文物信息、展览内容、馆务服务、参观政策、基建导览；
- **智能 QA 机器审查（机审）**：
  - **自动关联依据**：平台自主生成的问答自动携带生成时的原文依据，无需重复上传文件，一键即可启动机审；
  - **支持外挂补充资料**：支持外部导入问答或需比对最新资料时，按需上传补充文档（最大 100 MB）并自动建立语义索引匹配；
  - **逻辑与事实核查**：基于大模型对答案事实真实性、是否有依据、口吻通俗度进行全方位审查，支持一键采纳修改建议；
- **多维度评测集生产**：
  - 覆盖标准问答、同义改写、口语表达、要点完整性、抗幻觉边界 5 类评测维度；
  - 默认由大模型出题（按 4 条 QA/批、3 批并发调用，兼顾生成质量与响应速度）；
  - 标准问答基准题直接取自来源 QA（零 Token 消耗，保证标准答案绝对一致）；
  - 评测集支持覆盖率分析、逐条审核编辑，并可导出 Excel 或 JSON；
- **数据隐私与模型安全**：
  - 业务数据和审核参考资料持久化保存在浏览器本地（IndexedDB / localStorage），不经第三方服务器；
  - 提供本地服务端安全代理 `/api/llm`，API Key 仅留存当前会话内存，严防泄露。

## 本地运行

```bash
npm install
npm run dev
```

浏览器打开终端显示的本地地址，通常为 `http://localhost:3000/`。

## 推荐导入格式

最简单的直接导入问答格式：

| 问题 | 答案 |
| --- | --- |
| 博物馆几点开放？ | 开放时间请以馆方当日公告为准。 |

亦可直接导入包含“文物名称、年代、材质、工艺、出土地、尺寸、纹饰、价值”等多字段的普通资料表，或直接拖入带文字图层的 Word / PDF 展陈大纲，系统会自动按金牌讲解员的叙述逻辑提炼多维问答。

## 评测集生产流程

1. 优先选择“已通过”的 QA 作为标准答案来源；
2. 选择评测维度与出题引擎（默认大模型出题，按 4 条 QA/批并发生成，参考答案由系统本地回填）；
3. 生成与来源 QA 绑定的测试题，边生成边增量入库，实时检查分类与维度覆盖率；
4. 审核测试问题、参考答案、评分标准和必含关键词；
5. 导出标准 Excel 或 JSON，用于大模型能力评估、提示词调优或知识库版本回归测试。

## 模型配置与角色分配

系统内置独立模型注册表与 OpenAI Chat Completions 协议适配层：

- 支持配置与切换多个大模型（如 DeepSeek、GLM、通义千问等）；
- 支持多生产角色独立分配：QA 生成模型、QA 机器审核模型、评测集出题模型可按需独立配置，支持交叉审查；
- 内置速率限制重试与并发熔断保护机制，确保批量生成稳定可靠。
